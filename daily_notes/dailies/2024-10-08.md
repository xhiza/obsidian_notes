How can we tell if the data is up-to-date?

To check data integrity in the database, use this command:

```
checkdata -pers_volume_id 0 -mode data_integrity
```

To make sure all checksums are correct, use:

```
checkdata -pers_volume_id 0 -mode checksum
```
