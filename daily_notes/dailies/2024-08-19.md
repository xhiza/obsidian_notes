# August 19, 2024

Checking monitoring with [[Mihai]].
PostActions tries to send 'set_main_cluster_state' (which is missing)
The CloudFormation update attempt failed because it involved a non-standard operation: updating, deleting, or getting an SSM parameter. According to Irakli, the issue stems from the initial setup where the database was running on c4 version 4.13, which doesn't support CloudFormation template updates. The database was subsequently upgraded to @saas-8.28.4 using an older method (stopping all nodes), and that update was successful. However, c4 attempted to update the CloudFormation template today for reasons that are not known, resulting in a failure due to missing policies.
