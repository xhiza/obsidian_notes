## Notes
- Backoffice: tested shared deployment behavior and pushed for clearer support-facing CLI guidance. In particular, an expired session should tell the operator the full proper command rather than only `backoffice session start`, and an already-running database should return a clearer "already running, no operation" style message.
- Provider decoupling: supported the solution where `saas-terraform` modules declare an AWS provider floor while each root pins its own version. This prevents future dependabot bumps from breaking both real AWS and LocalStack e2e in lockstep.
- Go-utils/hashcheck: root cause work showed a failed `aws s3 cp` could still write `source-hash.txt`, causing future runs to skip redeploy even though `deployment.zip` was missing. Follow-up work exposed the unmanaged hashcheck bucket and missing cross-account read access for customer-account Lambda updates.
- Tooling/AI workflow: noticed Claude-generated edits touching unrelated `docs/superpowers/plans/*.md` files in `saas-terraform`; discussed with Leila and Mihai and kept those changes out of the PR.
