# June 22, 2025

Found out that unattended-upgrades restarts c4_cloud_command on new Ubuntu 24.04 LTS. We had to add a conf to not restart the service.

```
/etc/needrestart/conf.d/exasol.conf

# Do not automatically restart c4_cloud_command
# because that's the service which runs the whole
# Exasol stack of services, including databases.
$nrconf{override_rc}{qr(^c4_cloud_command\.service$)} = 0;

```
